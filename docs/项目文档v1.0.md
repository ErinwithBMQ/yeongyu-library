## 基本信息
- 名称：小章鱼存档地
- 形式：web 网页
- 定位：产出整理站+匿名树洞
- 牢记核心定位：小章鱼存档地不是【论坛】，是【产出整理站】，稍微提供一个【交流平台】。对于所有产出，全部平等对待，不做热度推荐、收藏夹分享等功能（当然，电台里是可以推荐文的，这个不拦着）。
 
## 技术框架
- Baas（后端即服务）。采用 Supabase 或者 LeanCloud
- Next.js + TailwindCSS
- Vercel 部署
- 我还得去买个域名，然后阿里云DNS云解析
- 前端需要做电脑和手机双端的适配

## 风格要求
简约可爱风格
主色调为樱花粉色+薄荷绿色。可选白天黑夜模式

## 网页版块及功能
四个版块：图书馆，电台，收藏夹，我

### 图书馆
#### 作品条目
这里先定义一个作品条目所要包含的内容：
1. 作品名称
2. 作者名
3. 直达url
4. 发布平台
5. 简介（一般是复制作者发表平台上的简介。可选）
不会显示收藏人数。

#### 标签系统
作品的整理是标签系统。一个作品可以有多个标签。
【必选】作品类型标签：同人文，捡手机，论坛体，视频剪辑，条漫/漫画
【除视频剪辑外必选】大标签：现实背景向，架空现代，架空幻想，架空古代
【同人文必选】篇幅标签：短打，短篇，中篇，长篇
【同人文，捡手机必选】进度标签：连载中，已完结
情感基调标签：甜文、虐文、酸甜、搞笑、正剧、暗黑
提示标签：BE，OE，R18，主要角色死亡，非双洁，SM，性转
剧情定位标签：破镜重圆，竹马竹马，校园，娱乐圈，公司职场，先婚后爱，穿越，宫廷，江湖，仙侠
常见人设标签：黑帮，杀手，站街，网簧，有生理/心理疾病
常见特殊设定标签：HP设定，abo设定，cake&fork设定，哨向设定，赛博朋克
幻想设定标签：花吐症，机器人/仿生人，末日，幽灵/鬼魂/妖精，天使恶魔，吸血鬼，小动物，人鱼

#### 作品查找
按选中的标签进行查找。
给出两种排序：按照首字母排序，按照加入图书馆的时间排序

#### 精确搜索
两种：根据作品名搜索，根据作者搜索

#### 随机来一个
根据选中的标签，完全随机抽取一个作品条目

#### 添加，删除，修改条目
如题。
添加条目时，需要检索是否已经有url一样的条目。若有，则无法添加。

### 电台
真心定格电台。匿名树洞定位。

#### 留言提交
就是正常的在输入框写文字然后提交。只能写文字，不能上传图片。
提供作品条目引用功能。可在留言下方引用条目，点击后直达条目详情页面。
可自定义留言人名称。

#### 留言展示
由于采用注册申请制，留言提交后可直接展示。因为可自定义留言人名称，展示是就是“来自xxx的留言：……”
其他用户可以贴表情（提供表情选择），不可以评论。
系统会根据留言长短更改展示方式。具体地：
- 如果是 **150字以内** 的短句：系统自动判定为“碎碎念”。
	- 在页面上显示为“便利贴”。适合简短的“今天也好喜欢准奎！”、“打卡”。
- 如果是 **长篇大论**：系统自动判定为“来信”。
	- 在页面上显示为“信封”。只显示前两行摘要，点击展开才能看全文。适合写“入坑的心路历程”、“读后感”。
此外就还是条目引用，若有引用则在留言最下方显示跳转按钮。

### 收藏夹
每个用户的收藏夹只有自己才能看见。可以创建多个收藏夹。收藏的是作品条目。

### 我
就是基本的修改密码。

### 其他功能：注册登录
注册需要的信息：
1. 邮箱
2. 用户名
3. 密码
4. 确认密码
5. 邀请码

首先需要通过填写我的问卷以获得与邮箱唯一对应的邀请码。注册时，会检验邀请码是否有效，与注册邮箱是否匹配。匹配后才可成功注册。

问卷提供两种审核方式：①准奎超话等级大于等于 9 级 ②填写问题答卷，满分100，大于等于80分。问题都是关于准奎的糖点

登录需要的信息：
邮箱和密码。

## 用户身份

游客，认证用户，管理员

游客：只可以访问图书馆页面，进行搜索及随机来一篇。对条目进行修改、电台、收藏都不能用。
认证用户：开放以上提到的所有功能
管理员：可以直接操作数据库进行所有操作，比如对违规留言、违规用户进行删除。

## 人员招募

技术人员：
1. 前端 UI 设计人员 若干
	- 要求：有较好的审美，良好的版面布局意识。有 UI 设计经验者优先。
2. 前端编码人员 若干
	- 要求：掌握 JavaScript 语言，有良好的编程习惯，会使用 git 进行团队协作。有 react/next.js/vue 等前端框架经验者优先。
3. 数据库管理人员
	- 要求：掌握 SQL 基本语法，熟悉 PostgreSQL 数据库。

管理人员：
1. 问卷管理及分发人员 若干
	- 这部分人员是负责邀请码问卷的制作、管理与审核。
2. 存档地账号运营
	- 负责存档地官方账号在xhs、wb等平台上的运营，收集用户反馈，发布公告等。
3. 树洞内容监察员
	- 负责匿名树洞留言的监察，及时清理不好的留言。

其他：
1. 条目迁移志愿者
	- 负责将旧图书馆的条目筛选出有效条目，迁移至新图书馆
