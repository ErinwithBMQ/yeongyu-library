# 电台功能使用说明

## 功能概述

真心定格电台是一个匿名树洞功能，用户可以在这里留下自己的碎碎念或长信，并与其他用户通过表情进行互动。

## 主要特性

### 1. 留言提交

- **昵称自定义**：每次留言可以自定义显示的昵称（最多20字符）
- **内容输入**：支持纯文本输入，会自动根据字数判断展示类型
  - ≤150字：显示为"碎碎念"（便利贴样式，粉色背景）
  - >150字：显示为"来信"（信封样式，白色背景，默认折叠）
- **作品引用**（可选）：可以引用图书馆中的作品，显示为可点击的链接卡片

### 2. 留言展示

#### 碎碎念（便利贴）
- 粉色渐变背景
- 全文直接显示
- 适合简短的心情记录

#### 来信（信封）
- 白色背景
- 默认只显示前两行 + "..."
- 点击"展开阅读"查看全文
- 适合长篇的读后感、心路历程等

### 3. 表情互动

- 预设6种表情：❤️ 😭 😂 👍 🎉 💕
- 每个用户对每条留言的每种表情只能点一次
- 点击表情会切换状态（添加/取消）
- 显示每种表情的总数
- 用户点过的表情会高亮显示（粉色边框）

### 4. 引用作品

- 可以在留言中引用图书馆的作品
- 引用显示为带图标的绿色卡片
- 点击可直接跳转到作品详情页

## 技术实现

### 数据库表

1. **radio_messages**：存储留言
   - user_id：发送者ID
   - nickname：自定义昵称
   - content：留言内容
   - linked_work_id：引用的作品ID（可选）
   - created_at：创建时间

2. **radio_reactions**：存储表情反应
   - message_id：留言ID
   - user_id：点击用户ID
   - emoji：表情字符
   - 唯一约束：(message_id, user_id, emoji)

### API 服务

位于 `src/services/radio.ts`：

- `getRadioMessages(page, pageSize)`：获取留言列表
- `postRadioMessage(params)`：发送新留言
- `toggleReaction(messageId, emoji)`：添加/移除表情
- `getMessageReactions(messageId)`：获取留言的表情统计

### 组件

- **RadioMessageCard** (`src/components/RadioMessageCard.tsx`)：单条留言的展示卡片
- **RadioPage** (`src/app/radio/page.tsx`)：电台主页面

## 权限要求

- 游客：无法访问电台功能
- 认证用户：可以发送留言、添加表情
- 管理员：额外权限需在数据库层面操作

## 使用流程

1. 用户登录后访问电台页面
2. 在左侧表单填写昵称和留言内容
3. （可选）选择要引用的作品
4. 点击"投递留言"按钮
5. 留言会立即显示在右侧列表中
6. 其他用户可以通过点击表情与留言互动

## 注意事项

- 留言一旦发送无法编辑，请谨慎填写
- 昵称可以每次留言时更改，实现"匿名"效果
- 表情反应是实时更新的
- 留言按时间倒序排列（最新的在最上方）
